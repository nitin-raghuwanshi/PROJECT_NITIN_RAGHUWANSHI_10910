## 📌 Project Title
Student Attendance Management System

## 📖 Project Description
This project is developed using the C programming language to create a simple
Student Attendance Management System.
It records, displays, and counts the attendance of students using a 1D array.

In this system:
1 represents Present  
0 represents Absent  

The program takes attendance input for each student, displays individual
attendance status, and calculates the total number of present and absent students.

## 🎯 Objective of the Project
- To understand the use of 1D arrays
- To practice loops and conditional statements
- To store and process attendance data
- To build logic using if-else conditions

## 🛠️ Tools & Technologies Used
- Programming Language: C  
- Compiler: GCC  
- Code Editor: VS Code  

## 🧠 Concepts Used
- 1D Arrays
- Loops (for)
- Conditional Statements (if-else)
- Functions
- Array Traversal

## ⚙️ Algorithm / Working Steps
1. Declare a 1D integer array for storing attendance
2. Decide 0 for Absent and 1 for Present
3. Use a loop to take attendance input for each student
4. Store input values in the array
5. Display attendance status of each student
6. Initialize counters for present and absent students
7. Traverse the array using a loop
8. If value is 1, increment present counter
9. If value is 0, increment absent counter
10. Display total present and absent students
